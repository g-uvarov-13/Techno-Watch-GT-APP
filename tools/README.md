# Инструменты

Проверка готового APK: `python tools/verify_public_assets.py --root . --apk releases/Chasovoy-1.0.0-release.apk` из корня репозитория.

Парсеры форматов и генераторы сохранены для дальнейшей разработки. Генераторы не запускаются при сборке Android. Некоторые требуют дополнительных базовых пакетов, изображений и манифестов; наличие скрипта не обещает полного пересоздания галереи. Читайте входные параметры и DEVELOPER_GUIDE.md перед запуском.

Генераторы диагностических анимаций, анализ отдельной видеосессии и старый проверяющий инструмент исключены из публичного комплекта вместе с зависимыми скриптами. Полезные генераторы циферблатов сохранены. Пути `C:/Windows/Fonts` в инструментах отрисовки описывают локальную зависимость Windows, а не персональные данные; на другой ОС нужен подходящий шрифт с разрешённым использованием.

Метки состояния в исходных манифестах относятся к соответствующему этапу подготовки материалов, а не к текущей физической приёмке приложения. Хеши и сведения происхождения не следует подменять.
