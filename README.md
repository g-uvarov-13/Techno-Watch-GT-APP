# Часовой 1.0.0

«Часовой» — Android-приложение для TECNO Watch GT (профиль GT01), создания собственных циферблатов, передачи уведомлений и просмотра показателей часов. Проект также содержит дневники тренировок и питания и дополнительный анализ через личный ключ OpenRouter.

Установка собственных циферблатов, уведомления и получение показателей подтверждены на физических часах. Это подтверждение относится к проверенному GT01 и конкретным известным сценариям; оно не означает совместимость со всеми часами TECNO или всеми версиями прошивки. Тренировки, питание и OpenRouter ещё требуют полной проверки и обкатки. В известном случае запросы OpenRouter останавливаются на этапе `CONNECT`; версия 1.0.0 не заявляет устранение этой сетевой проблемы.
Для использования приложение отключите стоковое My Health, либо другое взаимодействующее с часами, т.к оно будет мешать соединению.
## Что можно делать

- Выбирать встроенные циферблаты и доступные для них цветовые варианты.
- Создавать циферблат из изображения, двигать фон и размещать время, дату, шаги, калории, последний пульс, заряд и расстояние.
- Сохранять редактируемые проекты `.gtdial`, делиться ими и готовить пакеты `.dial` на телефоне.
- Устанавливать подготовленный циферблат через известный путь передачи GT01.
- Передавать новые уведомления выбранных Android-приложений после выдачи доступа к уведомлениям.
- Просматривать полученные наблюдения активности и здоровья с учётом доступности и времени источника.
- Вести локальные записи тренировок и питания; дополнительные сетевые функции включаются по отдельному действию пользователя.

## Быстрый старт

1. Установите APK из выбранного вами выпуска. Android 8.0/API 26 или новее и Bluetooth LE обязательны. Сверьте версию и опубликованную контрольную сумму файла, если они предоставлены.
2. Откройте настройки подключения, выдайте запрашиваемые разрешения Bluetooth и выберите свои часы.
3. Дождитесь готовности соединения. Подробная инструкция находится в [руководстве пользователя](USER_GUIDE.md).
4. Для своего циферблата откройте вкладку «Часы» → «Мои циферблаты» → создание проекта. Сохранение и подготовка выполняются локально; запись на часы начинается отдельной кнопкой установки.

Не выбирайте устройство только по похожему имени: проверьте, что это ваши часы. После ошибки установки посмотрите итог операции и состояние устройства. Ошибочный запрос не повторяется автоматически.

## Исходники и выпуск

В `android/` находится Android-проект на Java с Gradle Kotlin DSL. В `tools/` — инструменты автономного анализа форматов циферблатов. Встроенные пакеты и исходные ресурсы редактора лежат в `android/app/src/main/assets/`; для обычной сборки APK их не нужно пересоздавать.

Успешная сборка и статические проверки не доказывают корректность на физических часах. Версию APK, подпись, контрольные суммы и результаты проверки конкретного выпуска определяет сопровождающий проекта. Не заменяйте сертификат подписи существующей установки без согласованного плана обновления.
